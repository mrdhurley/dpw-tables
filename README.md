# Dragonfly Pond Works Tables

This repository hosts comparison tables for the Dragonfly Pond Works service category pages.

## Tables

- **Pond & Lake Management**: [pond-lake-management-table.html](https://mrdhurley.github.io/dpw-tables/pond-lake-management-table.html)

## Usage in Brizy

Embed tables using iframe:

```html
<iframe src="https://mrdhurley.github.io/dpw-tables/pond-lake-management-table.html" style="width:100%; height:500px; border:0;" scrolling="no"></iframe>
```

## Adding to Brizy Custom Fields

1. Create a custom field (Text type)
2. Paste the iframe code above
3. Connect the field to your template
4. Adjust height as needed
